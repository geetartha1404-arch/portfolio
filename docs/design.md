\# Design System --- Portfolio

\## Design Philosophy - Minimal, clean, and modern - Warm, calm base
with subtle visual contrast - Focus on clarity, not decoration - Every
element should have a purpose

\-\--

\## Color System

\### Base (Neutral) - Background: #F5F1E8 (Soft beige) - Surface:
#FFFFFF (Cards, sections) - Border: #E5E0D8

\### Text - Primary: #1A1A1A - Secondary: #555555 - Muted: #888888

\-\--

\### Accent Colors (Used Sparingly)

Primary Accent: - #6366F1 (Indigo)

Secondary Accent: - #F59E0B (Amber)

Optional Accent: - #10B981 (Emerald)

Rules: - Use accents for buttons, highlights, and links only - Never use
more than 2 accents in the same section - Beige must dominate the visual
tone

\-\--

\## Typography

\### Font Style - Sans-serif (modern, clean)

Recommended: - Inter - Satoshi - Geist

\### Scale - H1 → Bold, large, attention-grabbing - H2 → Section
headers - Body → Clean and readable - Small text → Muted, low emphasis

Rules: - Strong hierarchy - Avoid excessive font weights - Keep line
length readable

\-\--

\## Layout

\### Structure - Max width: 1100--1200px - Centered layout - Generous
padding

\### Spacing - Follow consistent spacing scale (Tailwind) - Use
whitespace intentionally

\-\--

\## Components

\### Cards - White background - Soft shadow - Rounded corners (lg or
xl) - Slight hover lift

\### Buttons Primary: - Solid accent color - Clear call-to-action

Secondary: - Outline or subtle background

Hover: - Slight scale or color shift

\-\--

\## Interaction & Motion

\### Principles - Subtle and smooth - Fast (150ms--300ms)

\### Effects - Fade in on scroll - Hover scale (1.02--1.05) - Soft
transitions

\-\--

\## Visual Style

\- Clean grids - Balanced spacing - No clutter - Modern UI patterns
(cards, sections, hero blocks)

\-\--

\## Imagery

\- High quality, minimal - Use screenshots of projects - Avoid
stock-heavy visuals

\-\--

\## Do NOT

\- Do not use harsh or neon colors - Do not overcrowd sections - Do not
mix too many styles - Do not overuse animations

\-\--

\## Stitch Usage Guidelines

When generating drafts: - Maintain beige-dominant palette - Use accent
colors sparingly - Keep layout minimal and structured - Prioritize
readability over creativity

For previews: - Focus on hierarchy and spacing - Ensure visual
consistency across sections - Avoid unnecessary elements

\-\--

\## Goal

Create a portfolio that feels: - Calm but modern - Simple but not
boring - Professional but visually distinct
