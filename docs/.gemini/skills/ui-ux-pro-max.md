# UI-UX Pro Max Skill

Elevate your UI/UX designs with advanced spatial compositions, typography, and motion.

## Design Philosophy
- **Bold Visual Hierarchy**: Use scale and contrast to guide the user's eye.
- **Intentional Motion**: Use spring physics and shared element transitions for a fluid feel.
- **Sophisticated Typography**: Move beyond system fonts; use variable fonts with custom weights.
- **Spatial Composition**: Utilize whitespace as a functional element, not just a gap.

## Implementation Guidelines
- **Grid Systems**: Use 8pt grids for consistency.
- **Color Systems**: Define semantic color variables (primary, secondary, surface, outline).
- **Motion Paths**: Prefer non-linear easing (cubic-bezier) for natural movement.
- **Responsive Design**: Transition between mobile-first and desktop-optimized layouts seamlessly.

## Anti-AI Slop
- Avoid generic "modern" card layouts.
- Remove unnecessary shadows and gradients that don't add depth.
- Focus on clean, high-contrast interfaces.
